# Long-Term Research Plan

## Time commitment

10 hours per week.

Suggested allocation:
- 4 hours: observational data and analysis
- 3 hours: software development and experiments
- 2 hours: scientific literature and theory
- 1 hour: documentation and reproducibility

## Phase 1: Observational foundations

- Establish reproducible Python environment.
- Read FITS observations and metadata.
- Identify an accessible high-resolution dataset.
- Reproduce a documented event from the literature.
- Establish measurement and data-quality procedures.

## Phase 2: Event detection

- Develop a classical image-processing baseline.
- Detect candidate events and track them over time.
- Create a manually reviewed reference catalog.
- Measure precision, recall, and false positives.
- Test generalization across separate observations.

## Phase 3: Physical diagnostics

- Analyze spectral line profiles.
- Examine magnetic flux evolution.
- Add temporal relationships and event morphology.
- Evaluate evidence for candidate physical mechanisms.
- Quantify ambiguity and uncertainty.

## Phase 4: Machine learning

- Compare image-only and multimodal models.
- Use independent observation sequences for testing.
- Report uncertainty and model failure modes.
- Compare with established detection methods.

## Phase 5: Research adoption

- Produce an inspectable event catalog.
- Develop tools for researcher review.
- Seek expert evaluation.
- Release reproducible scientific results.
- Prepare publications when supported by findings.

These phases are not tied to graduation or a fixed
completion date. Scientific results determine progress.
