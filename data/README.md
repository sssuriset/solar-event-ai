# Data Management

raw/ contains original downloaded observations.
processed/ contains derived datasets.

Observations should retain:
- Original filename and archive source
- Instrument and observation identifier
- Date, time, wavelength, and spatial metadata
- Calibration level
- Any processing or quality-control steps

Large observations are excluded from Git.
